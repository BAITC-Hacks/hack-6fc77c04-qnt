# PDF fonts

Noto Sans Regular and Bold from the Noto Fonts project:
https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf/NotoSans

Licensed under the SIL Open Font License 1.1, reproduced in OFL.txt.
The browser loads these same-origin fonts only when exporting an estimate.
They are embedded as subsets so Cyrillic, Kazakh and the tenge sign are selectable and display without installed fonts.
