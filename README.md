# QNT · Firebird

**Умный подбор подрядчиков для мероприятий**

Задайте город, дату, формат и бюджет — получите до трёх подходящих подрядчиков с объяснением выбора и фактами из каталога. Соберите понравившихся в предварительную смету и скачайте PDF.

**[Открыть демо](https://qnt.l33t.kz/)** · [Как работает подбор](docs/PLAN.md) · [API-контракт](docs/API_CONTRACT.md) · [Проверка проекта](docs/ORGANIZER_AUDIT.md)

![Предварительная смета выбранных подрядчиков](docs/assets/estimate-desktop.png)

## Что умеет

- **Подбирает по условиям.** Код проверяет занятость, формат, бюджет, язык и длительность, затем показывает до трёх вариантов из каталога 66 профилей. Порядок выдачи не зависит от AI.
- **Объясняет каждый выбор.** Карточки показывают проверенные условия, цитаты из описаний и причины отсева. AI может выбрать цитату; без ключа работает локальное объяснение с явной меткой `local`.
- **Собирает предварительную смету.** Выбранных подрядчиков можно добавлять и заменять. Черновик хранится в браузере; PDF создаётся там же, без отправки сметы на сервер.

Цены указаны **«от» за подрядчика на мероприятие**. Смета не является бронированием или полной стоимостью события.

## Запуск без API-ключа

Нужны Python 3.10–3.12 и Node.js 22.12+. Из корня репозитория:

```bash
cd frontend
npm ci
npm run build
cd ..
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r backend/requirements.txt
python -m uvicorn app.main:app --app-dir backend --host 127.0.0.1 --port 8000
```

Откройте **http://127.0.0.1:8000/**. Сервер отдаёт интерфейс и `/api` с одного адреса. AI-ключ не требуется: по умолчанию используются локальные объяснения, а UI-деморежим выключен. На Windows PowerShell активируйте `.venv\Scripts\Activate.ps1` и при необходимости используйте `npm.cmd`.

```bash
python backend/scripts/judge_check.py
```

Эта команда запускает проверки сервера и интерфейса, сборку и контрольные сценарии без платных AI-вызовов. Отдельно: `cd frontend && npm test` или `python -m pytest -q backend/tests`. Последний [локальный отчёт](docs/verification-results.json) и [сценарии приёмки](docs/ACCEPTANCE.md) доступны в документации. GitHub Actions пока не выполняет задания из-за блокировки billing аккаунта; успешный CI не заявляется.

## Границы проекта

Каталог предоставлен организатором кейса: 66 анонимизированных профилей, часть записей синтетическая, некоторые значения города и цены дополнены и помечены в интерфейсе. [Происхождение и ограничения данных](data/README.md). Календарь охватывает **23.09–31.12.2026**; отсутствие отметки о занятости не подтверждает доступность подрядчика. Описания и начальные цены нужно уточнять перед заказом. Поиск в интернете, заявки, оплата и бронирование не входят в MVP.
