## Как продолжить совместно

После публикации интеграции в main каждый участник сначала проверяет `git status`, сохраняет свои изменения в своей ветке, затем выполняет `git fetch origin` и `git merge origin/main` в своей рабочей ветке. Не делать reset/force-push и не перезаписывать чужие файлы. Бекзат сохраняет владение frontend и UI_QA, Естай — backend/data/интеграцией/деплоем. Локальный `.env` и ключи между участниками не пересылаются.
