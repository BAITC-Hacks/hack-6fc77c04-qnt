# QNT · Firebird — умный подбор подрядчиков

**[Открыть демо](https://qnt.l33t.kz/)** · Кейс №6 HackAlem AI · [План MVP](PLAN.md) · [API-контракт](API_CONTRACT.md)

Организатор задаёт город, дату, формат, категорию и бюджет на одного подрядчика. Сервис проверяет условия по учебному каталогу и показывает до трёх подходящих вариантов: начальную цену **«от»**, объяснение выбора и факты-основания. Язык и длительность можно указать как дополнительные обязательные условия. Пустая или короткая выдача объясняется — условия не меняются автоматически.

Публичный релиз `2c200812164a` был проверен 23.09.2026: HTTPS, настоящий каталог и API, три исхода подбора. Результаты проверки — в [отчёте интеграции](INTEGRATION_QA.md). Изменения после этого релиза и доступность сайта в текущую минуту нужно проверять отдельно.

## Как это выглядит

**Основной сценарий:** Алматы · ведущий · корпоратив · 11.10.2026 · до 1 000 000 ₸ на одного подрядчика · русский · 4 часа. Три карточки в порядке API, объяснения `local`; у первой раскрыты исходные факты. Снимок сделан с настоящим локальным backend и исходным каталогом, с выключенным UI-деморежимом.

**Нет подходящих:** тот же запрос с бюджетом 1 000 ₸. API вернул `no_matches`; экран показывает причины последовательного отсева и кнопку изменения условий. Это корректный результат поиска, не ошибка сети.

## Запуск без ключа

Нужны Python 3.10–3.12 и Node.js 22.12+. Из корня репозитория:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r backend/requirements.txt
cd frontend
npm ci --no-audit --no-fund
VITE_DEMO_MODE=false npm run build
cd ..
ENABLE_AI=false python -m uvicorn app.main:app --app-dir backend --host 127.0.0.1 --port 8000
```

Откройте **http://127.0.0.1:8000/**. Для Windows PowerShell используйте `.venv\Scripts\Activate.ps1`, `npm.cmd` и переменную `$env:VITE_DEMO_MODE = 'false'` перед сборкой. API доступен на `/api/options`, `/api/match` и `/docs`. Серверный ключ для локального подбора не нужен: карточки показывают отметку `local`.

`VITE_DEMO_MODE=true` включает отдельные вымышленные UI-фикстуры с постоянным баннером. Такой режим не проверяет каталог или backend. В обычной сборке он выключен. Для разработки можно запустить `npm run dev` внутри `frontend`: относительный `/api` проксируется на локальный сервер 8000.

## Что означает результат

Сначала сервер фильтрует город и категорию, затем последовательно проверяет занятость, формат, бюджет, указанный язык и длительность. Он возвращает до трёх карточек в детерминированном порядке. Возможны `matches_found`, `no_matches` и `category_missing`. Причины исключения считают каждого кандидата только по первому неподходящему условию.

Цена **«от … ₸»** относится к одному подрядчику на мероприятие, а не ко всему событию. Отсутствие пометки о занятости в предоставленном календаре не подтверждает свободную дату и не является бронированием.

Карточка показывает режим объяснения: `local` — сервер выбрал фрагмент описания по локальным правилам; `ai` — модель выбрала исходную цитату для уже отобранного подрядчика. Итоговый текст строит сервер из проверенных фактов и цитаты. AI не меняет кандидатов, порядок, цены или фильтры. В [отчёте интеграции](INTEGRATION_QA.md) зафиксированы два успешных реальных AI-запроса; в приведённых выше локальных скриншотах модель не вызывалась. При недоступности AI подбор остаётся доступным с `local` объяснением.

Метки данных видны только когда соответствующий признак установлен:

| Метка | Значение |
|---|---|
| `synthetic` | Синтетический профиль исходного учебного каталога |
| `city_imputed` | Город дополнен в предоставленных данных |
| `price_imputed` | Начальная цена дополнена в предоставленных данных |

- [Исходный CSV организатора](https://drive.google.com/file/d/1uUCu-szctwaTaV0-Yfg3FKHY8M3lQ3vw/view) сохранён в [data/contractors.csv](../data/contractors.csv) без правок. В нём 66 профилей и 17 категорий. Имена вымышленные; 13 профилей синтетические, у 18 дополнена цена, у 8 — город. [Происхождение и SHA-256](../data/README.md).
- Отдельная лицензия датасета в просмотренных материалах не указана. [MIT-лицензия кода](../LICENSE) не задаёт автоматически условия использования CSV. Описания подрядчиков не проходили независимую проверку.
- Даты ограничены окном **23.09–31.12.2026**. Календарь и начальные цены — учебные данные; нет бронирования, оплаты, регистрации и связи с подрядчиком. Лексический приоритет формата — простая эвристика, не рейтинг качества.
