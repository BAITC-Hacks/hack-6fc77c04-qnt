## Воспроизводимые результаты

В отдельную временную папку скопированы только публикуемые исходники, без `.env`, `.state`, старого venv и node_modules. Создан новый Python 3.10 venv, выполнены `pip install -r backend/requirements.txt`, `npm ci --no-audit --no-fund` и `python backend/scripts/judge_check.py`.

- **94 backend-теста, 17 frontend-тестов**, production build — PASS. Один deprecation warning зависимости Starlette/AnyIO, не ошибка запуска.
- **30 600 запросов / 100 дней / 12 452 карточки**, 4,222 с локально, 0 платных обращений. Бюджет в полном переборе 10 млн ₸, без языка/часов; опциональные и пограничные условия проверяются отдельными тестами. Это не полный декартов перебор всех бюджетов и не HTTP-нагрузка.
- [Машиночитаемая приёмка](verification-results.json); [реальные AI-пробы](ai-eval-results.json); [сценарии и рубрика](../backend/tests/fixtures/explanation_eval.json).
- Браузер: настоящий локальный API, AI отключён; индивидуальные карточки, счётчики и занятость видны. На ширине 390 px карточка читается без горизонтальной прокрутки, ошибок в консоли не зафиксировано; это эмуляция ширины, не проверка физического телефона. Новый снимок: [decision-results.png](assets/decision-results.png).
- CI не запускался: GitHub runs `35851116571` (main) и `35851141487` (ветка Бекзат) остановлены блокировкой billing аккаунта, а не падением тестов. Локальный PASS не означает зелёный CI.

## Оценка готовности и оставшиеся риски

Обязательные технические сценарии проходят; это сильная база для допуска. Предсказать место или официальный балл нельзя без оценщика и работ остальных команд. Основной качественный предел — бедные исходные описания: у одного профиля даже лучший доступный факт слабый. Текущая небольшая рубрика не выявила преимущества AI над локальным алгоритмом (оба 25/26); нельзя представлять её как доказательство превосходства модели.

Перед сдачей остаются отдельные выпускные действия: согласовать интеграцию нового UI, проверить публичный релиз нужной версии, подтвердить сохранение формы и организационные условия. Они не замаскированы автоматическим PASS. Изменение биллинга, отправка формы и публикация на VPS этим аудитом не выполнялись.
