## Браузер: реальные действия и контролируемые сбои

Проверено в браузере Codex. Локальный `backend/scripts/ui_probe.py` использует реальный каталог, явно подставляет задержки/ошибки и никогда не вызывает модель; скрипт не включён в production-образ.

| Проверка | Наблюдение |
|---|---|
| Клавиатура | Enter отправляет форму и раскрывает «Факты-основания»; «Изменить условия» возвращает фокус в город |
| Бюджет 0 | Нативная валидация не даёт отправить; минимальное значение 1 |
| Изменение формы | Старые карточки очищаются |
| Гонка (`--mode race`) | Старый успешный запрос задержан на 4 с; новый бюджет 1 000 быстро даёт `no_matches`; поздний старый ответ не возвращает карточки |
| HTTP 503 (`--mode 503`) | Видимое сообщение об ошибке, параметры сохранены, можно повторить |
| Долгий ответ (`--mode timeout`) | При задержке 13 с UI через 12 с показывает таймаут, сохраняет параметры |
| Без ключа | Полный сценарий с исходными данными и маркировкой `local` |

Полная проверка Tab-порядка, экранных дикторов и всех браузеров не проведена. `invalid-json` доступен как отдельный режим локального пробника; не заявляется здесь как пройденная ручная проверка.
