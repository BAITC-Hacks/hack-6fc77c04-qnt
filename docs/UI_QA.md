# UI — передача Естаю

Ветка: `feat/contractor-ui`. Основа: `9cb0536` (общий коммит документов).
Изменения только в `frontend/**` и этом файле. Backend в локальной копии отсутствует.

## Запуск

Node.js 24.19.0. Из корня репозитория:

```powershell
cd frontend
npm.cmd ci
npm.cmd run dev
```

В обычном запуске деморежим выключен. `/api` проксируется на `http://127.0.0.1:8000` настройкой Vite, адрес не находится в компонентах. Production использует относительный `/api`; его маршрутизацию на сервер обеспечивает общая инфраструктура Естая.

Явный деморежим (PowerShell):

```powershell
$env:VITE_DEMO_MODE = 'true'
npm.cmd run dev
```

Открыть адрес Vite (обычно http://127.0.0.1:5173). Постоянный баннер: «Демонстрационные ответы интерфейса». Фикстуры вымышлены, не воспроизводят исходный каталог, его ранжирование или AI. Кнопки примеров заполняют форму; затем нажать подбор. Для примеров доступны 10 и 11 октября; неподдержанный набор параметров выдаёт явную ошибку фикстуры, а не выдуманный подбор.

Для реального API остановить Vite, установить `$env:VITE_DEMO_MODE = 'false'`, снова запустить Vite и backend на порту 8000. Vite считывает режим при запуске/сборке; после изменения режима нужна новая production-сборка. Ошибки реального API не переключают UI на фикстуры. Секреты не требуются.

```powershell
npm.cmd run build
npm.cmd test
```

Сборка находится в `frontend/dist`. Зависимости и lockfile только внутри frontend.

## Фактические проверки, 23.09.2026

- TypeScript и production-сборка Vite: PASS (Vite 7.3.6).
- Vitest: 12/12 PASS. Проверены инварианты всех четырёх фикстур (три карточки, одна, no_matches, category_missing), порядок причин и отсутствие двойного счёта, детерминированность и смена даты, ошибка неподдержанных демопараметров.
- Транспорт: проверены относительный URL, числовые значения и null в теле, ответы 422/503, не-JSON, сетевая ошибка, таймаут. Это модульные тесты с подменённым fetch, не интеграция с backend.
- Просмотр кода: текст рендерится через React без unsafe HTML; серверный порядок сохраняется; локальные объяснения помечены local; synthetic/city_imputed/price_imputed видны. При изменении полей запрос отменяется и его версия становится неактуальной; повторный запрос не принимает предыдущий результат.
- Сборка в Windows sandbox сначала была заблокирована доступом esbuild к родительской директории. Повторный запуск с разрешённым доступом завершился успешно.

## Ещё не проверено

- Визуальная проверка на телефоне/узком экране и реальная клавиатурная навигация: доступных браузеров нет, попытка создать in-app browser вернула `Browser is not available: iab`. Адаптивные CSS-правила для 760 и 360 px, label/input и focus-visible реализованы, но это не доказательство визуальной приёмки.
- Сценарий двух карточек, гонка медленных ответов и изменение формы во время запроса требуют браузерной проверки.
- Реальный API, реальные ID/ранжирование/календарь, границы бюджета/часов, null-лимит, занятые площадки, работа AI и его fallback: backend отсутствует. Не заявляются проверенными.
- До сдачи: открыть экран при ширинах 320/390/768/1280 px, проверить переполнение, видимость баннера, Tab/Enter, ошибки формы, раскрытие фактов; прогнать примеры на реальном backend, включая даты 10/11 октября и повтор одинакового запроса.

Публикация ветки и отправка сообщения Естаю требуют отдельного поручения. Хеш локального коммита передаётся в итоговом сообщении; его можно получить командой `git log -1 --format=%H`.
