## Изменения

Афишная композиция: крупная типографика, тёплый фон, киноварный акцент, карточки-билеты с номерами. На широком экране результат занимает большую часть рабочей области. Системные шрифты, без новых зависимостей, внешних ассетов и анимаций.

Сохранены заголовок «Нужные люди. Под ваше событие.», форма и сценарии API. QNT — команда, Firebird — кейс. Технические названия известных фактов заменены русскими подписями; значения и порядок сервера не меняются. Сохранены цена «от», AI/local и synthetic/city_imputed/price_imputed. Пояснено участие программного кода и AI; учебный календарь не обещает бронирование.

Рядом с кнопкой поиска показан статус. Явная кнопка переводит фокус к результату; завершение запроса не вызывает автоматической прокрутки. Поля имеют размер шрифта 16px, кнопки и раскрывающиеся факты — высоту не менее 44px.

- `npm.cmd test --prefix frontend`: 12/12 PASS. Фикстуры и транспорт: 422/503, не-JSON, сеть, таймаут. Это модульные проверки с подменой fetch.
- `npm.cmd run build --prefix frontend`, `VITE_DEMO_MODE=false`: PASS, TypeScript + Vite 7.3.6. HTML 0.44 kB (gzip 0.33), CSS 7.92 kB (2.33), JS 236.41 kB (74.20). Суммарно примерно 244.77 kB / 76.86 kB gzip. QA-скриншоты не входят в dist.
- Production UI с настоящим текущим FastAPI на `127.0.0.1:8001`, `ENABLE_AI=false`, без ключа. Headless Microsoft Edge, Playwright из временного окружения; пакет не добавлен в зависимости приложения.
- Ширины 320, 375, 390, 768, 1024, 1440 px: реальные три карточки, раскрытие фактов, сохранение порядка имён и всех значений evidence, бюджет 1000 ₸ → no_matches, отсутствие горизонтального переполнения. Это эмуляция размеров, не физические телефоны.
- Реальный API: category_missing («Нет категории»), короткая выдача («Редкие флористы»), local-объяснения; повтор после ошибки возвращает реальную выдачу.
- Клавиатура: Enter на переходе переводит фокус к заголовку результата, Enter раскрывает факты. Связи label/input, размер полей и высота summary проверены автоматически.
- Перехват в браузере: 503 показывает ошибку без карточек и без демоподмены, параметры сохраняются. Отложенный ответ после изменения формы не возвращает старые карточки; следующий реальный запрос корректен. Искусственные две карточки, AI, три флага и очень длинное имя проверены на 320 px. Это проверки отображения, не реальная генерация AI.
- Отдельный Vite на 5174 с `VITE_DEMO_MODE=true`: виден демобаннер, три карточки, запросов к API нет. В production баннер отсутствует и запросы идут к реальному backend.
- Во время сценариев ошибок JavaScript не обнаружено. API-клиент не изменён: таймаут 12 секунд и защита от устаревших ответов сохранены.
- Скриншоты настоящей выдачи: `frontend/qa/screenshots/editorial-1440.png`, `editorial-390.png`; визуально просмотрены.

Повтор браузерной проверки: запустить backend с текущим production dist, задать `PLAYWRIGHT_MODULE_PATH` к установленному вне проекта Playwright, затем `node frontend/qa/editorial.cjs`. При другом адресе задать `QA_ORIGIN`. Скрипт требует Edge и обновляет два QA-скриншота.
