# QNT Match — UI/UX и интеграционная проверка

Проверено 23.09.2026 в ветке `feat/contractor-ui`. Изменения только в `frontend/**` и `docs/UI_QA.md`.

## Интеграция и изменения

Текущие изменения package.json/lockfile были сохранены через scoped stash. Выполнены `git fetch origin` и `git merge origin/main`: fast-forward до `9314cf8`, без конфликтов. Stash восстановлен без конфликтов. Исходный коммит Бекзат `cfa205a` и авторство сохранены; локальный main не изменялся.

- Главный бренд — QNT Match; Firebird №6 — вторичный. Системные шрифты, адаптивная сетка, контрастные поля и фокус, кнопки от 44 px, текст полей 16 px.
- Ошибки ввода рядом с полями, связанные `aria-describedby`/`aria-invalid`; фокус на первом ошибочном поле. Календарь сохраняет контрактное окно. Положительные дробные часы допускаются, необязательные значения отправляются как null.
- После ответа нет автоматической прокрутки или переноса фокуса. Рядом с кнопкой появляется статус и явная кнопка «К результатам»: только её нажатие прокручивает и фокусирует заголовок выдачи.
- Подписи evidence переведены: начальная цена, формат, занятость по календарю, основание порядка, язык, лимит часов, цитата из описания. Значения, тексты и порядок API не изменяются. Неизвестный технический ключ получает нейтральную подпись «Факт из каталога».
- Отметки local/AI и synthetic/city_imputed/price_imputed сохранены с русскими пояснениями. Никаких собственных фильтров или сортировки.
- Отмена старого запроса и проверка его версии сохранены. Таймаут — 12 секунд, включая чтение тела ответа; исправлена потеря сообщения о таймауте во время чтения JSON.
- Оригинальный знак QNT: SVG, ICO 16/32/48 px, Apple PNG 180×180. Оригинальная OG-картинка PNG 1200×630. Исходный генератор — `frontend/scripts/create-brand-assets.ps1` (Windows/System.Drawing, UTF-8 BOM). Картинки не заимствованы.
- HTML содержит русский title/description, lang, charset, viewport, theme-color, OG и Twitter Card. Настройка абсолютного URL описана ниже.
- Новые зависимости только для разработки: Playwright и Prettier. Runtime-зависимости прежние — React/React DOM. Внешних шрифтов, изображений, видео, аналитики и новых API-запросов нет.

## Воспроизводимый запуск

Из корня, отдельный терминал для настоящего API, без ключей:

```powershell
python -m venv frontend/.qa-venv
frontend/.qa-venv/Scripts/python.exe -m pip install -r backend/requirements.txt
$env:PYTHONDONTWRITEBYTECODE = '1'
$env:ENABLE_AI = 'false'
frontend/.qa-venv/Scripts/python.exe -m uvicorn app.main:app --app-dir backend --host 127.0.0.1 --port 8000
```

Здесь проверено на Windows, Python 3.13.15, Node.js 24.19.0, Vite 7.3.6, Edge 153.0.4234.48. README рекомендует Python 3.10–3.12; эта итерация не меняет серверные требования. Окружение, кэши и отчёты проверок внутри frontend игнорируются Git.

Во втором терминале:

```powershell
cd frontend
npm.cmd ci
$env:VITE_DEMO_MODE = 'false'
$env:VITE_PUBLIC_SITE_URL = 'https://qnt.l33t.kz'
npm.cmd test
npm.cmd run build
npm.cmd run test:build
npm.cmd run test:ui
```

`test:ui` требует запущенный backend на 8000 и свободные порты 5173/5174; сам поднимает Vite в обычном и деморежимах. Windows использует установленный Edge. На Linux/macOS предварительно установить Chromium командой `npx playwright install chromium`. Тесты и браузер не включаются в production bundle. Отчёты/скриншоты — `frontend/test-results/`, не коммитятся.

После сборки UI доступен непосредственно через настоящий backend: http://127.0.0.1:8000/. Для разработки — `npm.cmd run dev`, http://127.0.0.1:5173; `/api` проксируется на `127.0.0.1:8000`. URL backend не зашит в компоненты.

Деморежим включается исключительно `$env:VITE_DEMO_MODE = 'true'` перед запуском Vite или сборкой. Для возвращения к API поставить `false` и перезапустить/пересобрать. По умолчанию режим выключен. Баннер «Демонстрационные ответы интерфейса» постоянный; фикстуры вымышлены, без сервера/AI, поддерживают готовые примеры и даты 10/11 октября. Ошибка настоящего API не подменяется фикстурой.

## Фактические результаты

- `npm.cmd test`: **37/37 PASS**, включая исходные 12 тестов. Валидация, границы дат/чисел, null, подписи evidence, настройки social URL, транспорт, 422/503/не-JSON/сеть/таймаут.
- `npm.cmd run build`: **PASS**, результат в `frontend/dist`.
- `npm.cmd run test:build`: **PASS** без заданного домена и с `https://qnt.l33t.kz`. Проверены итоговый HTML, ссылки на JS/CSS/favicon/Apple icon, размеры PNG и структура ICO; в обычном JS bundle отсутствует демобаннер.
- `npm.cmd run test:ui`: **19/19 PASS** в headless Edge. Это реальный браузерный движок с эмуляцией размеров окна, **не физический телефон**.
- Настоящий `/api/health`: `ok`, 66 профилей. Обычный UI работает с реальным backend, API-ключ не задан, объяснения local.
- Алматы / ведущие / 10.10 / 1 млн / русский / 4 ч: четыре подходящих, три карточки в серверном порядке `HK-88430 → HK-29829 → HK-27222`. Значения evidence сравниваются с API без изменений.
- 11 октября меняет выдачу; повтор одинакового запроса возвращает тот же ответ. Бюджет 700 000 даёт две карточки с серверным объяснением сокращения.
- Редкие флористы: одна карточка `HK-39372`, серверное объяснение короткой выдачи. Бюджет 1 000: `no_matches`. Зарубежье + флорист: `category_missing`. Пустые состояния различимы, кнопка изменения условий фокусирует город.
- Ширины **320, 375, 390, 768, 1440 px**: нет горизонтального переполнения в начальном состоянии, реальной выдаче с раскрытыми фактами и стресс-сценарии длинного текста без пробелов. Скриншоты всех пяти ширин просмотрены. Поля/кнопки не меньше 44 px, поля имеют label, шрифт полей не меньше 16 px.
- Проверены Tab и видимый фокус, Enter для отправки/раскрытия evidence, фокус на ошибочных дате/бюджете, min/max календаря. Ввод вне диапазона не отправляет запрос.
- На 390 px завершение ответа не меняет scrollY и не фокусирует результаты самовольно; явная кнопка переводит к заголовку. Медленный старый ответ после изменения параметров не перезаписывает новый.
- Настоящий серверный 422 показан в UI (тест подменяет только исходящий запрос на недопустимую дату). Отдельно **инъекцией ответов** проверены 422/503, HTML вместо JSON и разрыв сети: видимая ошибка, форма сохранена, повтор успешен, демоданных нет.
- Зависший запрос в браузере завершается сообщением через 12 секунд и разблокирует кнопку. Это имитация зависания транспорта.
- AI-метка и все флаги проверены на **подменённом ответе**, не на реальном AI. Строка с `<script>` остаётся текстом. Деморежим проходит три исхода и не обращается к API.
- Production HTML, JS/CSS, SVG/ICO/Apple/OG-картинки обслуживаются настоящим backend на 8000, HTTP-ссылки локально рабочие; ошибок загрузки запросов в этом тесте нет.
- Расчёт контраста: основной текст на белом 12.09:1, вторичный на фоне 5.57:1, акцент заголовка 5.33:1, рамка поля 3.20:1, фокус 5.24:1. Это проверка выбранных пар цветов, не полный аудит WCAG.

## Задачи Естаю при интеграции/деплое

1. Домен `https://qnt.l33t.kz` взят из README интеграции `9314cf8`, не придуман. До запуска `npm run build` задать `VITE_PUBLIC_SITE_URL=https://qnt.l33t.kz`, `VITE_DEMO_MODE=false`. Параметры не содержат секретов.
2. В текущем `Dockerfile.prod` переменная social URL не передаётся. В своей зоне Естаю нужно добавить ARG/ENV в frontend-stage **до** `RUN npm run build` или обеспечить frontend `.env.production` на этапе сборки. Переменная только на Python runtime не меняет готовый HTML. Эти деплой-файлы Бекзат не редактировала.
3. Без настройки домена сборка работает, но `og:image`/`twitter:image` сознательно отсутствуют. При настройке в итоговый статический HTML вставляется абсолютный `https://qnt.l33t.kz/og-qnt.png`; неверный HTTP/credential/path URL отклоняется. Команда `npm run test:build` запускается с тем же окружением, что и сборка.
4. После деплоя проверить публичные `/`, `/api/health`, `/favicon.svg`, `/favicon.ico`, `/apple-touch-icon.png`, `/og-qnt.png`, MIME-типы, HTTPS и raw HTML OG/Twitter. Проверить реальное превью ссылки в чатах с учётом кеша.
5. Проверить на физическом Android/iPhone: нативный календарь, экранную клавиатуру, Safari/Chrome, переход к результатам, масштабирование, реальное медленное соединение; отдельно screen reader. Пройти примеры на публичном API в инкогнито.

Публичный сайт, превью в чатах, физический телефон, нативные мобильные date-picker, Safari/Firefox и screen reader **не проверены**. Реальный вызов AI не выполнялся. CI/контейнер/деплой — вне этой итерации. Локальные проверки не являются доказательством публичной готовности.

Первоначальные проверки `cfa205a`: 12 unit-тестов и сборка на фикстурах без backend. Настоящий backend и браузерные сценарии проверены в текущей итерации, как описано выше.

Push, merge в main и деплой не выполнялись. Для публикации ветки требуется отдельное подтверждение Бекзат согласно её инструкции; хеш локального коммита будет в итоговом сообщении.
