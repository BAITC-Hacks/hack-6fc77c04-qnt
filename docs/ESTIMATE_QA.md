## Поведение

Смета хранит выбранного подрядчика вместе с точным запросом, по которому он был показан. Это локальный черновик рекомендаций, не заявка. Сумма складывается из `price_from_kzt`, не умножается на часы и не сравнивается с бюджетом на одного подрядчика как с бюджетом всего события.

- Выбор разных категорий для одного города/даты/формата; один ID не добавляется дважды.
- Замена предзаполняет все семь условий. Исходная позиция сохраняется до успешного выбора замены, включая пустую выдачу и отмену.
- Изменение города/даты/формата/категории отменяет режим замены, не переписывая смету.
- Другое событие требует явного действия «Начать новую смету»; предложение переводит фокус к подтверждению. Даже тот же ID на другую дату может запустить этот сценарий.
- Версионированный localStorage, проверка сохранённых данных, безопасная работа в памяти при недоступном хранилище. Смета не является серверной записью; разные вкладки автоматически не синхронизируются.
- TXT-экспорт содержит условия, отметки synthetic/imputed и предупреждение о предварительном расчёте. В режиме UI-демо реальный сохранённый черновик не читается и не перезаписывается.
